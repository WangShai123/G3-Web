# G3-Web

`G3-Web` 是一款现代化的 `WordPress` 插件，提供横向（系统应用层）和纵向（开发扩展层）的双向扩展能力。旨在帮助用户快速构建强大的 `WordPress` 主题和应用，敏捷响应业务需求：

- 增强 WP 应用能力，更好满足现代数字化运营需求。
- 帮助 WP 用户快速搭建功能完备、稳定可靠的 Web 项目，并实现轻松维护。
- 助力中小创业者以超低成本实现跨平台运营、业务实验及系统私有化部署。
- 赋能每一位有创意的用户，将创意想法转化为数字化解决方案。

## 🛜 项目路径

`wp-content/plugins/g3-web/`

## 🚀 核心特性

### 架构特性

- **现代 PHP 8.3+** —— 采用最新 PHP 特性和语法规范
- **PSR-11 容器** —— 符合 PSR-11 标准的依赖注入容器
- **组件化架构** —— 模块化、按需加载的组件系统，支持主题覆写
- **RESTful API** —— 基于注解的 REST API 路由系统
- **中间件支持** —— 灵活的中间件机制，配套完备的 API 权限控制
- **重写系统** —— 基于配置文件的 URL 重写系统
- **AOP 编程** —— 支持面向切面编程

### 功能模块

- **队列系统** —— 异步任务处理
- **缓存系统** —— Redis 对象缓存支持
- **用户认证** —— 微信登录及第三方社交账号登录
- **内容管理** —— 增强的文章管理、浏览统计、版权保护
- **电商功能** —— 商品管理、订单系统、SKU 管理
- **微信集成** —— 微信公众号管理与消息处理
- **安全防护** —— 多层安全防护机制
- **支付系统** —— 集成多种支付方式
- **以及更多功能**
